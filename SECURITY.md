# Security Policy — Notepad OS

## Reporting a Security Vulnerability

If you discover a potential security vulnerability within **Notepad OS**, please report it responsibly.

> **Do NOT publicly disclose security vulnerabilities on public GitHub issues or discussions until a patch is available.**

### How to Report

Please report security issues directly to the maintainers via email or private GitHub security advisory reporting:

- **Repository**: [https://github.com/sajidhossain8272/notepad-os/security/advisories](https://github.com/sajidhossain8272/notepad-os/security/advisories)

Please include:
1. Description of the issue and potential impact.
2. Steps to reproduce or proof-of-concept code.
3. Affected versions and operating system details.

We will acknowledge receipt of your report within 48 hours and work with you to patch any confirmed vulnerability prior to public release.
