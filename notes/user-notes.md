# Quick Start Guide & Notes 🚀

Here are some helpful tips for using **Nodepad OS**:

### Keyboard Shortcuts

- `Ctrl + N`: Create a new note
- `Ctrl + S`: Instantly save active note
- `Ctrl + F`: Search all notes
- `Ctrl + P`: Toggle Markdown Live Preview
- `Ctrl + Shift + T`: Cycle through themes (Win95 -> WinXP -> Terminal -> Minimal)

### Customizing Settings

Click on **File > Settings** or the gear icon in the status bar to configure:
1. **Theme**: Choose between Windows 95, Windows XP, Terminal Green, and Minimal White.
2. **Font Size**: 12px, 14px, 16px, 18px, or 20px.
3. **Editor Font**: Consolas, MS Sans Serif, or Terminal Monospace.
4. **Live Preview**: Enable or disable side-by-side Markdown rendering.
