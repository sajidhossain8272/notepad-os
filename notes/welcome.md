# Welcome to Nodepad OS 📝

> **"Notepad from the past, redesigned for today."**

Nodepad OS is a tiny, ultra-fast, offline-first markdown editor inspired by the classic **Windows 95 Notepad**.

---

### Features

- ⚡ **Instant Startup**: Zero fluff, opens instantly
- 🔒 **100% Privacy First**: No cloud, no analytics, no tracking
- 🎨 **4 Retro Themes**: Windows 95, Windows XP, Terminal Green, Minimal White
- 📝 **Markdown Live Preview**: Split view or live markdown preview mode
- 💾 **Local Storage**: Notes saved locally in `./notes/` folder

### Markdown Formatting Examples

- **Bold text** with `**bold**`
- *Italic text* with `*italic*`
- Code blocks:

```javascript
function greetUser() {
  console.log("Hello from Windows 95 Nodepad OS!");
}
```
